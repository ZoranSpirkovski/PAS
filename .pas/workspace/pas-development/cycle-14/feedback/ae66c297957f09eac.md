Target: framework:pas
Degraded: Hook script crashes with "integer expression expected" error on line 65
Root Cause: The `tr -d ' '` command on line 65 of check-self-eval.sh removes only spaces but leaves trailing newlines from `wc -c` output. When LAST_MSG_LEN is assigned a value like "0\n0", the subsequent integer comparison on line 66 (`[ "$LAST_MSG_LEN" -gt 0 ]`) fails because bash interprets it as comparing two separate values.
Fix: Replace `tr -d ' '` with `xargs` to properly trim all whitespace: `LAST_MSG_LEN=$(echo -n "$LAST_MSG" | wc -c | xargs)`. This will properly handle the newline that `wc -c` appends to its numeric output.
Evidence: Error message shows "[: 0\n0: integer expression expected" on line 39 of the hook, which maps back to the integer test on line 66 receiving malformed input from line 65's whitespace trimming.
